# Trilium Notes

Hierarchical note-taking application. Notes can contain text, code, images, and files,
and can be linked together in a tree or with relations.

## Ports

| Port | Purpose |
|------|---------|
| 8080 | Web UI |

## Notes

- Notes are stored in an SQLite database in the data volume — no external DB needed.
- Desktop sync clients available for Windows, macOS, and Linux — sync via the server.
- Supports scripting notes (JavaScript) for custom automation within the note tree.
- Clone notes to reference the same note in multiple places in the hierarchy.
- **Official docs**: https://trilium.rocks/wiki/
