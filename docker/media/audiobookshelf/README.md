# Audiobookshelf

Self-hosted audiobook and podcast server with a mobile app for offline listening.

## Ports

| Port | Purpose |
|------|---------|
| 13378 | Web UI and API |

## Notes

- iOS and Android apps available — they sync progress and support offline downloads.
- Add audiobook and e-book libraries by pointing to directories on the NAS in the web UI.
- Podcast RSS feeds are managed directly in the UI.
- Per-user progress tracking with bookmark support.
- **Official docs**: https://www.audiobookshelf.org/docs
