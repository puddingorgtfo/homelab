# IT Tools

Collection of 100+ developer and IT utilities in a browser tab. Covers encoding/decoding,
hashing, format conversion, network tools, and more.

## Ports

| Port | Purpose |
|------|---------|
| 80 | Web UI |

## What's Included

Some of the tools available:

- Token/JWT decoder and generator
- Base64 / URL encoding and decoding
- UUID generator
- Hash generation (MD5, SHA-1, SHA-256, etc.)
- Regex tester
- JSON formatter and diff
- Cron expression parser
- Color picker and converter
- IP subnet calculator
- YAML ↔ JSON converter

## Notes

- Everything runs client-side in the browser — no data is sent to any server.
- **Official docs**: https://github.com/CorentinTh/it-tools
